# Settings Wireframe

> **URL:** `/settings/*`
> **Auth Required:** Yes
> **Priority:** P2 (MVP)

---

## 1. Overview

The Settings section allows users to manage their preferences, notifications, account, and data. Uses a sidebar navigation pattern with multiple sub-pages.

### Settings Pages
- `/settings/preferences` - Units, date/time, theme, tracking mode, display
- `/settings/notifications` - Email notification preferences, delivery, quiet hours
- `/settings/photos` - Photo upload quality, watermarks, sharing defaults
- `/settings/tags` - Create, edit, delete user tags
- `/settings/account` - Email, password, username
- `/settings/data` - Export data, delete account

## 9. Data Requirements

### 9.1 API Endpoints

| Action | Endpoint |
|--------|----------|
| Get settings | `GET /api/users/me/settings` |
| Update preferences | `PUT /api/users/me/settings` |
| Change email | `PUT /api/users/me/email` |
| Change password | `PUT /api/users/me/password` |
| Change username | `PUT /api/users/me/username` |
| List tags | `GET /api/tags` |
| Create tag | `POST /api/tags` |
| Update tag | `PATCH /api/tags/:tagId` |
| Delete tag | `DELETE /api/tags/:tagId` |
| Request export | `POST /api/export/request` |
| Delete account | `DELETE /api/users/me` |

### 9.2 Data Shapes

**User Settings:**
```typescript
interface UserSettings {
  // Basic preferences
  measurementSystem: 'Imperial' | 'Metric';
  dateFormat: 'MMDDYYYY' | 'DDMMYYYY' | 'YYYYMMDD';
  timeFormat: 'TwelveHour' | 'TwentyFourHour';
  timezone: string;
  theme: 'amber' | 'teal' | 'terracotta' | 'emerald' | 'slate' | 'blue';

  // Display settings
  firstDayOfWeek: 'Sunday' | 'Monday';
  showRelativeTimes: boolean;       // "3 days ago" vs absolute date
  fontSize: 'Small' | 'Normal' | 'Large';
  density: 'Compact' | 'Comfortable';

  // Tracking settings
  trackingMode: 'Easy' | 'Advanced';
  autoFillFromLastRun: boolean;     // Pre-populate from previous stage
  defaultHomeSection: 'ActiveCycles' | 'Dashboard' | 'Gallery';

  // Notification settings
  notifications: {
    stageReminders: boolean;
    comments: boolean;
    replies: boolean;
    uglyRocks: boolean;
    recipeCloned: boolean;          // When someone clones your recipe
  };
  digestFrequency: 'Instant' | 'Daily';
  quietHoursEnabled: boolean;
  quietHoursStart?: string;         // Time (e.g., "22:00")
  quietHoursEnd?: string;           // Time (e.g., "08:00")

  // Photo settings
  photoUploadQuality: 'DataSaver' | 'Balanced' | 'HighQuality';
  addWatermark: boolean;
  defaultPostVisibility: 'Private' | 'Unlisted' | 'Public';
}
```

interface Tag {
